# 绿萝土壤湿度标定记录

## 标定对象

- 植物：室内盆栽绿萝
- 传感器：土壤湿度模拟传感器，`AOUT/AUOT -> GPIO16`
- 固件换算范围：空气中干燥电压 `2740 mV -> 0%`，完全湿润电压 `1040 mV -> 100%`
- 注意：固件显示的百分比是当前传感器的相对湿度值，不是实验室测量的土壤体积含水率。
